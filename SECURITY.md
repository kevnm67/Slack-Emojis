# Security Policy

This repository contains static emoji image assets and a small helper
script for maintaining the README table. There is no runtime service,
API, or user data associated with this project.

## Reporting a Vulnerability

If you believe you've found a security issue (e.g. in the Python
script or CI configuration), please report it privately rather than
opening a public issue:

- Email [devsecops@locumtenens.com](mailto:devsecops@locumtenens.com), or
- Use [GitHub Security Advisories](https://github.com/kevnm67/Slack-Emojis/security/advisories/new).

## Supported Versions

This project does not maintain versioned releases with security
patches — only the latest `main` branch is supported.
